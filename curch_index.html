About

헌금 입력부터 기부금영수증까지
한곳에서 끝내는 재정 도구

교회회계는 실제 교회 재정 업무 흐름에 맞게 만든 웹 기반 앱입니다. 주일 헌금을 한 번에 입력하고, 예산 대비 집행 현황과 기간별 통계를 확인하며, 연말에는 교인별 기부금영수증을 PDF로 발행합니다. 스마트폰과 PC에서 함께 사용할 수 있습니다.

Church Accounting is a web-based finance app built for Korean churches. It covers batch offering entry, budget tracking, statistics, ledger printing and donation receipt issuing, and works on both smartphones and desktops.

Features

주요 기능

📝

헌금 일괄 입력

엑셀처럼 생긴 화면에서 여러 교인의 헌금을 한 번에 입력. 반복 등록과 초성 검색으로 입력 시간을 줄입니다.

📊

예산 · 통계

예산 대비 집행률과 기간별 통계를 자동 집계. 개인별 헌금, 대분류별 지출, 이자 합계까지 확인하고 엑셀·A4 인쇄로 내보냅니다.

🧾

기부금영수증 발행

교인을 선택하면 연간 헌금 합산액이 계산되고, 가족 합산도 지원. 서식을 미리 보고 인쇄·PDF 저장·공유까지.

🏦

계정 · 만기 관리

일반계정과 정기계정의 이월금·수입·지출·잔액을 연도별로 관리하고, 정기계정 만기일을 알려 줍니다.

👥

교인 명부

직분, 연락처, 가족 그룹과 세대 정보를 관리. 안 쓰는 교인은 숨김 처리해 입력 목록을 깔끔하게 유지합니다.

🔒

보안 · 백업

비밀번호로 입력 모드와 열람 모드를 분리. 클라우드 동기화와 주간 자동 백업, JSON·엑셀 내보내기를 지원합니다.

Workflow

사용 흐름

명부 · 항목 준비

교인 명부와 헌금·지출 항목, 계좌를 처음 한 번만 등록.

헌금 · 지출 입력

주일 헌금은 일괄 입력, 지출은 항목별로 간편하게 기록.

통계 · 장부 확인

예산 집행률과 월별·연간 통계, 월장부를 확인하고 인쇄.

영수증 발행 · 백업

기부금영수증을 PDF로 발행하고 데이터를 백업.
