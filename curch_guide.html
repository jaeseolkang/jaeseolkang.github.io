📒 교회회계 앱 사용설명서

앱 버전 v4.115 기준 · 수입/지출 입력부터 통계, 기부금영수증, 백업까지

목차 1. 시작하기 2. 입력 모드와 비밀번호 3. 홈 화면 4. 거래 입력·수정·삭제 5. 헌금 일괄 입력 6. 반복 등록 7. 예산 탭 8. 통계 탭 9. 계정 탭 10. 명부 탭 11. 기부금영수증 12. 설정 탭 13. 항목(분류) 관리 14. 백업과 복원 15. 자주 묻는 질문

1. 시작하기

교회회계 앱은 교회의 수입·지출, 계좌, 교인 명부, 기부금영수증을 한 곳에서 관리하는 웹앱(PWA)입니다. 스마트폰과 PC 브라우저 모두에서 사용할 수 있고, 데이터는 클라우드(Firebase)와 동기화됩니다.

화면 구성

화면 아래쪽의 탭 6개로 이동합니다.

탭용도
홈월 요약, 달력/일일/월별 내역, 거래 추가
예산연도별 예산 대비 집행 현황, 예산 편성 양식
통계기간별 수입·지출 통계, 개인별 헌금, 엑셀·인쇄
계정일반계정·정기계정(예금) 잔액과 만기 관리
명부교인 명부, 기부금영수증 발행
설정로그인, 계좌·항목 관리, 동기화, 백업

앱으로 설치하기

  • 안드로이드(크롬): 처음 접속하면 앱으로 설치하기 배너가 나타납니다. 설치를 누르세요. 배너를 닫으면(✕) 다시 나타나지 않습니다.
  • 아이폰(사파리): 공유 버튼 → 홈 화면에 추가를 선택합니다.
  • 설치하면 홈 화면 아이콘으로 실행되며, 화면이 꽉 차게 보입니다.
💡 앱을 열 때마다 새 버전이 있는지 자동으로 확인하고, 새 버전이 준비되면 화면이 자동으로 새로고침됩니다.

2. 입력 모드와 비밀번호

이 앱은 두 가지 모드로 동작합니다.

모드할 수 있는 일
🔒 열람 전용 모드내역·통계·계정 조회만 가능. 입력/수정/삭제는 막힙니다.
🔓 입력 모드데이터 입력과 수정, 삭제, 설정 변경이 모두 가능합니다.

입력이 필요한 기능을 열람 모드에서 누르면 "🔒 입력 모드에서만 사용 가능합니다" 안내가 나옵니다.

처음 비밀번호 설정

  1. 설정 탭에서 비밀번호 설정 화면을 엽니다.
  2. 4자 이상으로 사용할 비밀번호를 입력하고 저장합니다. 저장되면 바로 입력 모드로 전환됩니다.

로그인 / 로그아웃

  • 로그인: 설정 탭의 비밀번호 칸에 입력 후 로그인.
  • 로그아웃: 입력 모드 상태에서 로그아웃을 누르면 열람 모드로 돌아갑니다. 공용 기기에서는 사용 후 꼭 로그아웃하세요.

비밀번호 변경

  1. 입력 모드에서 비밀번호 변경을 누릅니다.
  2. 현재 비밀번호 확인 → 새 비밀번호(4자 이상) 입력 → 새 비밀번호 재입력 → 변경 저장.
⚠️ 비밀번호는 클라우드에 저장됩니다. 네트워크가 불안정하면 "네트워크 오류" 메시지가 나올 수 있으니 연결을 확인하고 다시 시도하세요.

3. 홈 화면

요약 카드

파란색 카드에 선택한 달의 요약이 표시됩니다. 카드 위의 ‹ › 화살표로 월을 이동합니다.

  • 전년이월: 지난해에서 넘어온 금액
  • 총수입 / 순지출 / 순수입계: 이번 달 합계 (통장이동은 수입·지출에서 구분되어 처리됨)
  • 총예금: 예금(정기계정) 관련 합계

보기 방식 3가지

보기설명
달력달력 형태로 날짜별 수입(초록)·지출(빨강)을 한눈에 봅니다. 날짜를 누르면 그날의 상세가 열립니다.
일일날짜별로 묶은 거래 목록. "오늘", "어제"로 표시됩니다.
월별월 단위로 모아 본 목록입니다.

내역이 없으면 "이번 달 내역이 없어요"와 함께 ＋ 버튼 안내가 나옵니다. 다른 계좌로의 이체는 ↔ 계좌이체로 표시됩니다.

하루 상세(날짜 패널)

달력에서 날짜를 누르면 그날의 거래 목록이 열립니다.

  • 위쪽 버튼으로 수입·지출을 새로 추가
  • 📊 헌금 일괄 입력 (여러 명 한 번에) 버튼으로 주일 헌금을 한꺼번에 입력 (5장 참고)
  • 이 날 거래가 없으면 "이 날의 내역이 없어요"가 표시됩니다.
  • 계좌 선택 시 🚫 안 쓰는 계좌 숨기기 관리로 쓰지 않는 계좌를 목록에서 숨길 수 있습니다. (대표계정은 숨길 수 없음)

4. 거래 입력·수정·삭제

거래는 대분류 → (중분류: 이름) → 세부항목별 금액 3단계로 입력합니다.

새 거래 입력 순서

  1. 홈의 ＋ 버튼 또는 날짜 패널에서 수입/지출을 선택해 새 거래 창을 엽니다.
  2. 항목 선택: 대분류를 고릅니다. (예: 헌금, 관리 및 유지비 등)
  3. 이름 선택: 대분류가 헌금처럼 사람 이름을 쓰는 경우, 목록에서 이름을 고릅니다.
    • 검색창에 이름 또는 초성(예: ㄱㄷㅎ)을 입력하면 빠르게 찾습니다.
    • 없는 이름은 + 중분류 추가로 즉시 추가합니다.
  4. 세부항목별 금액 입력: 십일조, 감사헌금처럼 세부항목마다 금액을 입력합니다. 자주 쓰지 않는 항목은 ▶ 추가 항목 더보기를 눌러 펼치고, 필요하면 새 세부항목 추가로 만듭니다.
  5. 필요하면 메모(선택)를 적고, 날짜와 계좌를 확인한 뒤 저장합니다.
💡 한 번 입력 화면에서 금액을 여러 세부항목에 동시에 입력해 저장할 수 있습니다. 최소 1개 항목에는 금액이 있어야 저장됩니다.

새 항목 추가

  • 항목 선택 화면의 + 새 항목 추가 / + 새 대분류로 즉석에서 추가할 수 있습니다.
  • 대분류를 먼저 고른 뒤 중분류(이름) 추가 또는 소분류 추가 중 하나를 선택합니다.
  • 이미 있는 이름은 "이미 있는 이름이에요"라며 막힙니다.

안 쓰는 이름 숨기기

이름 선택 화면의 🚫 안 쓰는 이름 숨기기 관리에서 체크한 이름은 헌금 입력 목록에서 보이지 않습니다. 명부의 숨김교인 설정과 같은 값이라 한 곳에서 바꾸면 양쪽에 반영됩니다.

계좌 선택과 통장이동

  • 계좌 구분: 일반계정, 정기계정. 대표계정은 기본으로 선택됩니다.
  • 통장이동은 계좌 사이 자금 이동으로, 수입·지출 통계와 분리되어 처리됩니다.
  • 계좌가 없다면 설정 > 연결계좌 관리에서 먼저 추가하세요.

수정 · 날짜 변경 · 삭제

  • 수정: 내역에서 거래를 눌러 내용을 고치고 수정 완료.
  • 날짜 변경: 날짜 선택 창에서 새 날짜를 골라 적용합니다.
  • 삭제: "이 거래를 삭제할까요?"에서 확인하면 삭제됩니다. 되돌릴 수 없으니 신중히 하세요.

5. 헌금 일괄 입력

주일 헌금처럼 여러 교인의 헌금을 한꺼번에 입력하는 엑셀형 화면입니다.

  1. 홈에서 입력할 날짜를 눌러 날짜 패널을 엽니다.
  2. 📊 헌금 일괄 입력 (여러 명 한 번에)을 누릅니다.
  3. 가로는 헌금 종류, 세로는 교인 이름인 격자에서 해당 칸에 금액을 입력합니다.
  4. 맨 아래 일괄 저장을 눌러 한 번에 저장합니다.
⚠️ 입력 단위는 천원입니다. (예: 50000원 → 50) 저장 전 화면 상단의 "명 · 총" 합계를 꼭 확인하세요.

화면 상단 버튼

버튼기능
👥 교인 가리기체크한 교인을 이 화면과 개별 헌금 입력 목록에서 숨깁니다. (명부의 숨김교인과 같은 설정)
🏷️ 항목 가리기체크한 헌금 종류를 이 일괄 입력 화면에서만 숨깁니다. 개별 입력 화면에는 그대로 보입니다.
🗑️ 입력삭제저장하지 않은 입력 내용을 모두 지웁니다. 지운 뒤에는 복구할 수 없습니다.
일괄 저장입력한 모든 금액을 거래로 저장합니다. 금액이 한 칸도 없으면 저장되지 않습니다.

반복 금액 자동 채우기

개별 입력에서 🔄 반복 등록한 교인(매주 같은 금액을 내는 분)은 일괄 입력 화면에서 이름이 파란색으로 표시됩니다. 이름을 탭하면 등록된 반복 금액이 그 행에 자동으로 채워집니다. 안내 문구: "파란 이름 탭 → 반복 적용"

💡 표시할 교인이나 헌금 종류가 없다고 나오면, [교인 가리기]/[항목 가리기]의 숨김을 풀거나 명부 탭에서 교인을 추가하세요.

6. 반복 등록

같은 사람이 같은 금액을 규칙적으로 내는 경우 한 번만 등록해 두면 편합니다.

  1. 거래 입력 화면에서 세부항목 금액을 입력합니다.
  2. 🔄 반복 등록을 누르면 "반복 등록됐어요" 메시지와 함께 저장됩니다.
  3. 다음부터 같은 이름·대분류로 입력할 때 🔄 반복 적용으로 금액을 한 번에 채웁니다.
  4. 더 이상 필요 없으면 반복 해제.

반복 템플릿은 대분류 + 이름 조합마다 1개씩 저장됩니다. 금액을 먼저 입력하지 않고 반복 등록을 누르면 "금액을 먼저 입력해주세요"가 표시됩니다.

7. 예산 탭

연도별 예산과 실제 집행 현황을 비교합니다.

  • 연도 선택으로 해당 연도를 봅니다.
  • 구분: 전체 요약 / 수입 예산 / 지출 예산. 각각 합계와 집행률(%)이 표시됩니다.
  • 예산이 없으면 "설정된 예산이 없어요"가 표시됩니다. 헌금종류별 예산은 항목 관리에서 소분류 예산을 설정해야 합니다.
  • 항목 관리 버튼으로 항목 구조와 예산 금액을 편집합니다. (13장 참고)

다음 해 예산 편성 (엑셀 양식)

  1. 예산 탭의 📥 예산양식을 눌러 엑셀 양식(예산편성_연도.xlsx)을 내려받습니다.
  2. 엑셀에서 노란 칸(중분류·소분류의 다음해예산)에만 금액을 입력합니다.
  3. 대분류·중분류 합계 칸은 수식으로 자동 계산되므로 직접 입력하지 마세요. 구분/대분류/중분류/소분류 열은 지우거나 순서를 바꾸면 안 됩니다.
  4. 앱에서 설정 → 예산 데이터 가져오기로 파일을 올립니다.
  5. "예산으로 반영할까요?"에서 확인하면, 값이 채워진 항목만 업데이트되고 나머지는 그대로 유지됩니다.
⚠️ 앱에서 내려받은 양식이 아니면 "양식을 인식할 수 없습니다" 오류가 납니다.

8. 통계 탭

선택한 기간의 수입·지출을 분석합니다. 화면 위에서 통계와 내용 보기를 전환합니다.

보기내용
통계대분류별 지출, 개인별 헌금액 등을 막대로 보여줍니다. 항목을 누르면 상세 내역이 열립니다.
내용헌금종류·대분류/소분류 단위 집계. 집계 항목을 누르면 상세가 열립니다.
리스트기간에 맞춘 거래 목록
이자선택 기간의 이자 내역과 이자합계. 이자가 없으면 "선택한 기간의 이자 내역이 없습니다"

기간 설정

주간 / 월간 / 연간 / 기간설정 중에서 고릅니다. 기간설정은 시작일과 종료일을 직접 지정합니다.

내보내기와 인쇄

  • 📥 엑셀: 통계를 엑셀 파일로 내려받습니다. (개인별헌금, 월지출, 월장부 형식 등)
  • 🖨️ 인쇄: A4 용지에 맞춘 통계 인쇄물을 만듭니다.

요약 숫자(전년이월, 통장이동, 이월잔액, 순지출, 순수입계)도 함께 표시됩니다.

9. 계정 탭

계좌별 잔액과 입출금을 관리합니다. 크게 일반계정과 정기계정으로 나뉩니다.

  • 이월금: 연초 이월 잔액 / 수입금 · 지출금: 해당 연도 합계
  • 자산합계, 정기계정 합계, 계좌 합계가 표시됩니다.
  • 정기계정에는 만기일이 함께 표시됩니다.
  • 연도 선택으로 연도를 바꾸거나 전체 연도로 누적을 봅니다.
  • 계정을 누르면 그 계좌의 거래 내역(재정→/→재정 이체 포함)이 열리고 📥 엑셀, 🖨️ 인쇄도 가능합니다.

등록된 계좌가 없으면 "설정 → 연결계좌 관리에서 추가하세요"가 표시됩니다.

연결계좌 추가·편집 (설정 > 연결계좌 관리)

  1. 계좌 추가 → 일반계좌 또는 정기계정 선택. (빠른 선택: 정기선교, 정기건축, 정기후대, 정기퇴직 등)
  2. 계좌 이름 입력 (예: 재정계정, 선교계정). 같은 이름은 만들 수 없습니다.
  3. 이월금액(원) 입력. 이전 기간에서 넘어온 금액입니다.
  4. 정기계정이면 만기일 입력(선택).
  5. 필요하면 대표계정으로 설정. 대표계정은 날짜 패널에서 기본 선택됩니다.
  6. 잘못 만든 계좌는 계좌 삭제로 지웁니다.

10. 명부 탭

교인 명부를 관리합니다. 명부에 등록하면 헌금 입력 시 이름으로 선택할 수 있습니다.

  • 필터: 전체교인 / 정교인 / 숨김교인
  • 정렬: 이름순 등
  • + 추가로 새 교인 등록, 목록의 교인을 눌러 수정
  • 엑셀로 내보내기 (교인명부 파일), 인쇄용 교인 명부 출력

교인 정보 입력 항목

구분항목
기본 정보이름(필수), 직분(예: 집사, 권사, 장로), 주민번호, 전화번호
가족 정보가족 그룹(예: 홍길동 가족), 세대(1~4세대), 가족 대표자
표시 설정숨김 여부 — 숨기면 헌금 입력 목록에서 빠집니다
⚠️ 교인을 삭제해도 기존 거래 데이터는 유지됩니다. 단, 이후 명부에서는 보이지 않습니다. 교회를 옮기셨거나 더 이상 입력하지 않는 교인은 삭제보다 숨김 처리를 권장합니다.
⚠️ 주민번호는 기부금영수증 발행에 사용되는 민감한 정보입니다. 입력 모드 비밀번호를 안전하게 관리하고, 공용 기기에서는 반드시 로그아웃하세요.

11. 기부금영수증

명부 탭의 기부금 버튼으로 들어갑니다. 소득세법 시행규칙 [별지 제45호의2서식] 형식으로 발행됩니다.

사전 준비 (설정 탭)

  • 교회 정보: 단체명, 사업자등록번호, 소재지 등을 입력합니다. 미입력 시 "교회 정보가 입력되지 않았어요" 안내가 나옵니다.
  • 직인(도장) 이미지: 배경이 투명한 PNG 권장, 2MB 이하. 미등록 시 "등록된 직인이 없어요" 안내가 나옵니다.

발행 방법

  1. 주 신청인(필수, 1명)을 이름 검색으로 고릅니다.
  2. 가족 합산이 필요하면 합산 대상 추가로 다른 교인을 더합니다.
  3. 귀속 연도와 발급일자를 선택합니다.
  4. 합산 금액을 확인합니다.
  5. 미리보기로 서식을 확인한 뒤 아래 중 하나를 선택합니다.
    • 🖨️ 인쇄 — 프린터로 출력
    • ⬇️ PDF로 저장 — 파일명 기부금영수증_이름 형식
    • 📤 공유하기 — 메일·카톡·문자 등으로 공유. 기기가 공유를 지원하지 않으면 PDF로 대신 저장됩니다.
💡 PDF 저장은 PDF 라이브러리가 필요합니다. "PDF 라이브러리를 불러오지 못했습니다"가 나오면 인터넷 연결을 확인하고 새로고침하세요.

13. 항목(분류) 관리

설정의 수입/지출 항목 관리 또는 예산 탭의 항목 관리에서 편집합니다. 구조는 3단계입니다.

  • 대분류: 예) 헌금, 관리 및 유지비, 선교비
  • 중분류: 예) 자동차, 교회당 / 헌금에서는 교인 이름이 들어갑니다
  • 소분류: 예) 자동차보험, 주유비 / 헌금에서는 십일조, 감사헌금 등 헌금 종류

할 수 있는 작업

  • + 새 대분류 추가, 중분류/소분류 추가·이름 수정
  • 소분류에 예산 금액 입력 (예산 편집 연도를 선택해 연도별로 설정)
  • 기본 항목 / 일반 항목 전환 — 기본 항목은 거래 입력 시 먼저 보이고, 나머지는 추가 항목 더보기에 들어갑니다.
  • 항목 삭제 시 거래가 있는 항목이면 다른 항목으로 이동할지 묻는 화면이 열립니다.
  • 🕘 예전 항목 보기: 연도별로 저장된 이전 항목 구조를 조회합니다.
💡 헌금 대분류는 교인이 수백 명이어도 항목구조표에 사람별로 펼치지 않고, 헌금 종류(소분류)만 중복 없이 모아서 보여줍니다. 명부 등록·개인별 입력·통계에는 영향이 없습니다.

14. 백업과 복원

⚠️ 회계 데이터는 정기적인 백업이 가장 중요합니다. 최소한 월말마다 JSON 백업을 받아 두세요.
기능설명
자동 백업켜 두면 매주 월요일 정오에 자동 백업됩니다. 백업 위치(폴더)를 지정할 수 있으며, 폴더 저장에 실패하면 다운로드로 대체됩니다. 마지막 백업 시각이 표시됩니다.
데이터 백업 (JSON)전체/개별 달/범위 설정 중 선택해 JSON 파일을 만듭니다. 파일 이름은 비워두면 자동 생성됩니다.
백업 메일 발송JSON을 등록된 이메일로 발송합니다. 먼저 설정에서 이메일을 등록해야 합니다.
엑셀로 내보내기거래 내역을 xlsx로 내려받습니다. 기간 범위를 지정할 수 있습니다.
주보 헌금명단헌금 수입만 뽑아 분류/내용 형식의 엑셀로 내보냅니다. (예금이자, 통장이동 등 헌금 이외 수입은 제외)
데이터 가져오기백업 JSON 파일에서 복원합니다.
예산 데이터 가져오기예산 양식 엑셀을 반영합니다. (7장)

복원 순서

  1. 설정 → 데이터 가져오기 선택
  2. 백업 JSON 파일 선택
  3. 안내 메시지를 확인하고 진행 → 완료 후 화면 새로고침
💡 복원 전에 현재 상태도 한 번 백업해 두면, 잘못 복원했을 때 되돌릴 수 있습니다.

15. 자주 묻는 질문

Q. 입력 버튼이 눌리지 않아요.

열람 모드일 가능성이 큽니다. 설정 탭에서 로그인해 입력 모드로 전환하세요.

Q. 새 버전이 반영되지 않아요.

설정 → 앱 업데이트를 누르세요. 그래도 같다면 앱을 완전히 종료한 뒤 다시 실행합니다.

Q. 다른 기기에서 입력한 내용이 안 보여요.

네트워크 연결을 확인하고 설정 → ☁️ 지금 다운로드로 최신 데이터를 가져오세요. 반대로 이 기기의 내용을 반영하려면 지금 업로드를 사용합니다.

Q. 헌금 입력 목록에 교인이 안 나와요.

숨김 처리되었을 수 있습니다. 명부 탭의 숨김교인에서 해제하거나, 입력 화면의 안 쓰는 이름 숨기기 관리를 확인하세요.

Q. 일괄 입력 금액이 이상해요.

일괄 입력은 천원 단위입니다. 50000원은 50으로 입력해야 합니다.

Q. 기부금영수증에 직인이 안 찍혀요.

설정에서 직인 이미지(PNG, 2MB 이하)를 등록했는지 확인하세요.

Q. 인쇄 용지는 무엇인가요?

통계, 월장부, 항목구조표, 기부금영수증은 A4 기준으로 출력됩니다.
